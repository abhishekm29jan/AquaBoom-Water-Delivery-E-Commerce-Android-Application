# 📱 About AquaBoom

AquaBoom is a modern **Water Delivery & E-Commerce Android Application** built using:

- Kotlin
- Jetpack Compose
- MVVM Architecture
- Firebase Services

The application is designed with a strong focus on:

✨ Premium UI/UX  
⚡ Scalable Architecture  
🔥 Real-Time Backend Integration  
🎨 Smooth Modern Animations  
🛍 Dynamic E-Commerce Features  
🔐 Secure Authentication Systems  

AquaBoom simulates a real-world startup-grade Android ecosystem featuring both:

- 👤 Customer Functionality
- 🔐 Admin Management System

# 🧠 Architecture

## 🏗 MVVM Architecture

AquaBoom follows a scalable and production-oriented MVVM architecture pattern.

```text
UI Layer (Jetpack Compose)
          ↓
ViewModel Layer
          ↓
Repository Layer
          ↓
Firebase Backend
```

# ⚡ Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/AquaBoom.git
```

---

## 2️⃣ Open In Android Studio

```text
Open Project → AquaBoom
```

---

## 3️⃣ Connect Firebase

Add your:

```text
google-services.json
```

inside:

```text
app/
```

---

## 4️⃣ Sync Gradle

Allow Gradle to sync all dependencies.

---

## 5️⃣ Run Application

▶ Build & Run the application on emulator or physical device.

---

# 📦 Gradle Dependencies

```kotlin
implementation("androidx.compose.ui:ui")
```
